# ScooterOS für ESP32-S3-WROOM-1-N16R8

**Datei:** [ScooterOS_ESP32S3_N16R8.bin](ScooterOS_ESP32S3_N16R8.bin)

- Modul: **ESP32-S3-WROOM-1-N16R8**
- Flash: **16 MB Quad SPI**
- PSRAM: **8 MB Octal SPI**
- PlatformIO-Build im ScooterOS-Quellrepository: `scooteros_s3_universal`
- Für GT2 Master und Slave ist dieselbe universelle Firmware vorgesehen. Die unterschiedlichen Rollen werden durch die jeweils passende `bios.json` und `vehicle.json` bestimmt.
