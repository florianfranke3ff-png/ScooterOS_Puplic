# ESP32-S3-WROOM-1

Für Varianten des **ESP32-S3-WROOM-1**. Die Firmware wird nach exakter Speicherbestückung aufgeteilt:

- [ESP32S3_N16R8](ESP32S3_N16R8/) – **16 MB Quad-SPI-Flash**, **8 MB Octal-SPI-PSRAM**.

Auch bei gleicher Speicherbestückung sollten Build-Konfiguration und Partitionstabelle vor dem Flashen geprüft werden.
